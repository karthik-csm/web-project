To demonstrate team collaboration using GitHub.

Project Description

This project demonstrates how to develop a web application using GitHub collaboration features such as branches, Issues, Pull Requests, and code reviews.

- Git
- GitHub

Procedure

3. Develop and commit changes.
4. Push the feature branch.
5. Create a Pull Request.
6. Review and merge the changes.
7. Update the README file.

Team collaboration using GitHub was demonstrated by creating a repository, managing a feature branch, and successfully merging a Pull Request.
